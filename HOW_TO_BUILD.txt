================================================================================
                   HOW TO BUILD CLINE EXTENSION LOCALLY
================================================================================

QUICK START (Copy-Paste This):
--------------------------------------------------------------------------------
git clone https://github.com/michkot/cline.git
cd cline
git checkout copilot/prepare-mr-text
npm run install:all
npm run protos
npm run package
npx @vscode/vsce package

# Then in VSCode: Extensions → "..." → Install from VSIX → select .vsix file
================================================================================
